# @enigma-tech-lab/angular

Accessible Angular 22 components in the Enigma Technology Lab design system, right to left ready: button, text field, select and dialog. Built on signals and the Angular CDK; styles come from [`@enigma-tech-lab/css`](../css).

```shell
pnpm add @enigma-tech-lab/angular @angular/cdk
```

```css
/* styles.css */
@import '@enigma-tech-lab/css/ui.css';
@import '@angular/cdk/overlay-prebuilt.css';
```

```ts
import { ButtonComponent, SelectComponent, TextFieldComponent, UiDialog, DialogComponent } from '@enigma-tech-lab/angular';
```

[Source and docs](https://github.com/Enigma-tech-labs/enigma-ui). MIT licence.
